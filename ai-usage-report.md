# AI Usage Report

## AI tool used
- Claude

## What I asked AI to do
1. Research the idea and build a prompt for it.
2. Cross-check the prompt and direction before implementation.
3. Create the frontend and related app structure.
4. Build the ticket system flow and supporting logic.
5. Add dummy data for the ticket system to test the workflow quickly.
6. Help iterate on the project while saving time in implementation.

## Most useful prompt
The most useful prompt was the one asking AI to add dummy ticket data for the system. This helped speed up the initial setup and gave a realistic ticket dataset for testing the dashboard and ticket flow.

## Code generated by AI
- The full codebase was generated with AI assistance.
- The dummy ticket data generation code was also AI-generated.
- I manually reviewed the generated code to catch issues and reduce risk before using it.

## What I modified manually
I manually reviewed the code to save time and fix weak areas in the generated output.

### Modified parts
- Dummy data generation
- Ticket assignment logic
- UI rendering for the submit button
- Ticket-to-staff assignment matching logic

## Where AI output was wrong
The AI-generated code had two important problems:

1. Submit button rendering issue
   - The button did not render correctly in the expected UI state.
   - This caused confusion in the ticket submission flow.

2. Ticket assignment was not working correctly
   - Tickets were not being assigned to the right person.
   - The logic was inconsistent with the expected routing pattern.

## How I identified the problem
I identified the root cause by reviewing the generated logic and checking the ticket assignment pattern against the expected string matching rules.

The core issue was that the assignment logic was not matching the category/department pattern properly. I fixed the logic by aligning it with the actual string pattern used in the ticket data and relevant staff mapping.

## Fix implemented
I fixed:
- the submit button rendering issue
- the ticket assignment logic based on string pattern matching
- the mapping so tickets are assigned to the correct staff member

## Summary
AI was useful for research, prompt building, frontend generation, and dummy data creation. However, I still had to manually review and correct the generated logic, especially around UI rendering and rule-based assignment. The final working behavior was achieved by tightening the assignment pattern matching and fixing the UI submit flow.
